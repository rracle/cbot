# cbot

Upbit 대상 코인 자동매매 봇. ATR 기반 추세추종 전략을 **백테스트 → 페이퍼 트레이딩 → 소액 실전** 순서로 검증하며 단계적으로 만들어가는 프로젝트.

> ⚠️ **면책**: 이 프로젝트는 학습 목적이다. 암호화폐는 원금 전액 손실이 가능한 고위험 자산이며,
> 백테스트 성과는 미래 수익을 보장하지 않는다. 실전 투입은 잃어도 되는 금액으로만.

## 전략

**돈치안 돌파 + EMA 추세필터 + ATR 리스크 관리** (4시간봉)

| 규칙 | 내용 |
|------|------|
| 진입 | 종가가 직전 20봉 최고가 돌파 **AND** EMA50 > EMA200 |
| 손절 | 진입가 − 2×ATR |
| 트레일링 스탑 | 진입 후 최고가 − 3×ATR (위로만 이동) |
| 포지션 사이징 | 트레이드당 총자본의 1% 리스크 → 수량 = 리스크금액 / (2×ATR) |

승률은 낮아도(30~40%) 손익비(~3)로 기대값을 만드는 구조. 손실은 짧게, 이익은 길게.

## 검증 결과 (2026-07 기준)

**KRW-BTC 4시간봉, 수수료 0.05% + 슬리피지 0.05% 반영**

| 기간 | 전략 | Buy & Hold | MDD | 거래수 | Profit Factor |
|------|-----:|-----------:|----:|-------:|--------------:|
| 333일 (하락장) | +1.3% | −42.4% | −6.7% | 13 | 1.15 |
| 5년 (풀사이클) | +78.4% | +138.5% | −8.1% | 94 | 2.12 |

- **5년 상세**: CAGR +12.2%, Sharpe 1.53, 최악의 해 −4.1% (B&H는 2022년 한 해 −63.2%).
- **성격**: 하락장에서 자본을 방어하고(시장 노출 ~15%), 상승장 수익의 일부를 포기하는 대신 낙폭을 한 자릿수로 통제한다.
- **견고성**: 4개 마켓(BTC/ETH/XRP/SOL)에서 방어 속성 일관, 파라미터 12개 변형 전 구간 흑자(절벽 없음 — 과최적화 아님). `uv run run_robustness.py`로 재현 가능.
- **알려진 약점**: 추세 없는 해에는 가짜 돌파로 잔손실이 누적된다 (ETH 하락장 −10.8%).

## 구조

```
Upbit API → data.py(캐시) → indicators.py → strategy.py → backtest.py → metrics.py
            └── exchanges/  (거래소 어댑터 — 코어는 거래소를 모른다)
```

| 모듈 | 역할 |
|------|------|
| `cbot/models.py` | 공통 타입 (Candle, Order, Position, Balance) |
| `cbot/exchanges/` | 거래소 어댑터 (`base.py` 프로토콜 + `upbit.py`) |
| `cbot/data.py` | 캔들 로컬 캐시 (`data/*.csv`) |
| `cbot/indicators.py` | EMA, ATR, Donchian |
| `cbot/strategy.py` | 진입/청산/사이징 규칙 |
| `cbot/backtest.py` | 이벤트 루프 백테스터 (다음 봉 시가 체결, 갭 처리) |
| `cbot/metrics.py` | CAGR, MDD, Sharpe, 손익비 등 성과 지표 |

전략·백테스트 코어는 거래소에 독립적이다. 다른 거래소는 `exchanges/`에 어댑터만 추가하면 된다.

## 시작하기

[uv](https://docs.astral.sh/uv/) 필요 (Python 3.12는 uv가 자동 관리).

```bash
uv sync                   # 환경 구성
uv run pytest             # 테스트 (28개)
uv run run_backtest.py    # KRW-BTC 백테스트
uv run run_robustness.py  # 견고성 검증 (마켓/기간/파라미터)
```
